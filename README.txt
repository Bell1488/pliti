ОСНОВА — обычный HTML, CSS, JavaScript

1. Распакуйте архив.
2. Откройте index.html двойным кликом. Интернет для отображения не нужен.
3. Для размещения загрузите index.html, styles.css, script.js, config.js и папку assets в корневой каталог сайта. Сборка и установка пакетов не нужны.

index.html — весь текст, ассортимент и цены.
styles.css — оформление и мобильная версия.
script.js — калькулятор, выбор плиты, проверка и отправка формы.
config.js — номер телефона и адрес обработчика заявок.
assets — локальное изображение и иконка.
PRICING.md — источники расчёта цен.
DEPLOY_VDS.md — пошаговый деплой на Linux VDS для premiumdoors.cc.

ОТПРАВКА ЗАЯВОК
Статический сайт сам не сохраняет и не пересылает заявки. Укажите leadEndpoint в config.js — адрес вашего серверного обработчика или сервиса форм. Обработчик должен принять JSON методом POST и вернуть JSON {"ok":true} после фактического сохранения/отправки заявки. При внешнем адресе нужен CORS для домена сайта. Отправка по умолчанию отключена и не показывает ложного сообщения об успехе.
Калькулятор, каталог, выбор плиты и вопросы работают без обработчика и без интернета.
Токены Telegram, пароли и другие секреты нельзя помещать в JavaScript. Они должны храниться только на стороне обработчика.

Перед рекламой добавьте контакты, реквизиты, политику обработки данных и Метрику; подтвердите цены. Телефон на сайте пока отсутствует по договорённости. Фото — иллюстрация, а не фото конкретного склада.
